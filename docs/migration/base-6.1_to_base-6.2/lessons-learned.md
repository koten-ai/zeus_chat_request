# Lessons: base-6.1 → base-6.2

## What worked

- **System diet dominates savings.** CORE compression: ~2.45k → ~1.42k tokens (~−42% system).
- **Triple-teach was real.** Collapsing `pipeline` terminating props to thin refs of `return` saved ~2.2k tool JSON chars per mode without dropping keys the model still needs by name.
- **Keep P0 laws explicit in short form:** no rediscovery, `order.asc` not `direction`, required four, progressive-empty one-liner — all still present after diet.
- **Client stamp enum out of CORE:** model only needs “never invent”; report_sink schema remains the machine SoT for `user`/`ip_address`.

## What we did not do

- Drop describe/explain or any of the 13 verbs (Hot Path / ZE-267 later).
- Runtime tools[] strip under enforcement.
- Move jailbreak into soft hints only.
